# Execution plans

Execution plans are living implementation documents.

Use them for:

- sequencing;
- progress;
- discovered constraints;
- temporary implementation choices;
- validation evidence;
- follow-up tasks.

Do not move durable architectural policy out of ADR/spec documents into plans.

## Agent rules

For a substantial task:

1. update/create an active plan;
2. keep a checklist with actual status;
3. record surprises and decisions;
4. include verification commands/results;
5. when complete, move/copy the finalized plan to `completed/` and create the next active plan if needed.

Avoid a single never-ending mega-plan.
