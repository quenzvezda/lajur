# Execution plan 0001 — Lajur MVP

**Status:** In progress  
**Owner:** coding agent + human reviewer

## Goal

Deliver a private/self-hosted v1 that proves the complete workflow:

`Android manual/offline entry → sync → XLSM canonical row → export`

Then add auth/app-lock and Smart Scan without destabilizing the workbook path.

## Guiding rule

Build thin vertical slices. Do not start with AI before workbook mutation and offline sync are proven.
