# Execution plan 0001 — Lajur MVP

**Status:** In progress  
**Owner:** coding agent + human reviewer

## Goal

Deliver a private/self-hosted v1 that proves the complete workflow:

`Android manual/offline entry → sync → XLSM canonical row → export`

Then add auth/app-lock and Smart Scan without destabilizing the workbook path.

## Guiding rule

Build thin vertical slices. Do not start with AI before workbook mutation and offline sync are proven.

Progress:

- 2026-09-20: completed the Phase 2 account/auth backend. Auth infrastructure uses a dedicated SQLite database, ASP.NET Core password hashing, persistent HMAC signing material, 15-minute JWT access tokens, and opaque rotating refresh tokens stored only as SHA-256 hashes with 30-day idle and 180-day absolute expiry. Login enforces the one-active-device policy; logout, device revocation, password reset, expired sessions, and replaced-token replay revoke the applicable session family immediately, including access-token validation on protected requests. Interactive operator commands create/reset accounts without public registration. Per-IP login/refresh rate limits return ProblemDetails-style errors. Integration tests cover rotation/replay, new-device revocation, logout/reset, hashed token persistence, account-owned device authorization, and immutable-ID-derived tenant storage paths. Finance endpoint isolation will be exercised again when those endpoints are added in Phase 3.
