# Workbook fixtures

Files in this directory contain synthetic test data only. They preserve the workbook structures needed by the XLSM adapter and preservation tests, but must never be generated by copying private values unchanged.

`LajurWorkbookFixture.xlsm` contains:

- the 12 monthly A:F transaction tables;
- synthetic Master categories, budgets, transaction types, and payment methods;
- a few synthetic transactions in January, February, September, and December;
- formulas, defined names, charts, PivotTables, controls, and VBA used by preservation tests.

The private production template under `private/` is not a test fixture and must remain ignored by Git.
